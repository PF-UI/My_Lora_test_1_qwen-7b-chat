# 小说角色对话数据集生成及lora微调

## 项目简介
本工具用于从任意小说文本（TXT格式）中自动提取指定角色的直接对话，生成结构化数据集，适用于角色语言风格微调场景。数据集将保留原文对话语境，并按统一格式整理，便于模型训练使用。


## 核心功能
1. **章节自动切分**：将小说全文按章节标题分割，提取各章节标题与内容
2. **对话提取与场景标注**：通过模型处理章节内容，提取目标角色的直接对话（带引号的口语表达），并标注对话场景（时期、地点、状态、对象等）
3. **结构化输出**：生成包含单轮对话、多轮对话链的JSON格式数据集
4. **错误日志**：自动记录处理过程中的错误信息，便于排查问题
5. **测试模式**：支持仅处理前几章内容，快速验证流程

## 注意事项
1. 确保模型服务可正常访问（默认使用本地API服务，需提前部署对应模型）
2. 若出现JSON解析错误，可查看`dataset_generation.log`日志文件排查问题
3. 输入文本需包含清晰的章节标题（如“第一章”“第1章”等），否则可能导致章节切分失败
4. 输出文件若已存在，将自动备份为`.bak.json`格式，避免覆盖原有数据
5. 角色对话提取规则可通过修改提示词模板调整，支持自定义场景标注维度和对话筛选条件
